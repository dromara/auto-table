# 问题说明

## 2.6.2 升级注意事项

### ⚠️ 重要提示：MyBatis-Plus 适配器变更

AutoTable 2.6.2 版本对 MyBatis-Plus 适配器进行了重大重构：

#### 变更内容

移除了 MyBatis-Plus 适配器的自定义扩展注解体系，回归零侵入设计理念：

**移除的注解：**
- `@Column` → 请使用 `@AutoColumn`（支持多数据库配置）
- `@ColumnId` → 请使用 `@PrimaryKey`
- `@Table` → 请使用 `@AutoTable`  
- `@UniqueIndex` → 请使用 `@Index` + `@TableIndex`

**保留的注解：**
- ✅ `@MysqlColumnUnsigned` - MySQL 无符号数字类型
- ✅ `@MysqlColumnZerofill` - MySQL 补零显示
- ✅ `@Ignore` - 忽略字段
- ✅ 所有标准注解保持不变

#### 如何判断是否需要升级？

如果您之前使用过以下导入语句，说明您使用了扩展注解：

```java
// ❌ 已废弃的使用方式
import org.dromara.autotable.mybatis.plus.spring.annotation.Column;
import org.dromara.autotable.mybatis.plus.spring.annotation.Table;
```

改为：

```java
// ✅ 推荐使用的方式
import org.dromara.autotable.annotation.AutoColumn;
import org.dromara.autotable.annotation.AutoTable;
```
